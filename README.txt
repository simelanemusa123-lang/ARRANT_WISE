HOW TO RUN
1. Extract the ZIP file.
2. Open the arrant_wise_website folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Navigate through the menu to view all seven pages.

IMPORTANT BEFORE GOING LIVE
- The email address, business hours, service descriptions, associations and other company details are starter content. Verify them with the client.
- The contact form is front-end only. It currently displays a demo success message and does not send or store enquiries. Connect a secure backend or a trusted form service before launch.
- Blog entries are placeholders and should be replaced with reviewed company content.
- Confirm permission to use all supplied images, logos and project photography.
- Add real social links, privacy policy, cookie notices if applicable, SEO metadata, analytics and hosting configuration as needed.
- The reference screenshot appears to contain company-specific claims and certification marks. Only publish verified certifications and affiliations.

DESIGN
Navy and royal-blue palette inspired by the reference, responsive layouts, image-led service cards, project gallery, CTA banners and a quote enquiry form.
